# Provider Key Documents – At a Glance

_Links checked: 2026-10-29. Research notes, not legal advice; have DPO/legal review before use._

## Summary

- Ten of the thirteen providers publish all their key legal and compliance documents.
- **Staan** publishes no terms of service, DPA, trust center or change notices. Those are only available at sign-up or on request.
- **Linkup** has no public DPA text (signable via DocuSign), no SCCs, no legal notice and no change notices. By default it processes queries in the US, EU, Canada and APAC.
- **Black Forest Labs** publishes no DPA ("available on request") and no change notices. Its self-serve terms let it train on our inputs and outputs.
- Details for each provider are in its note, under "Key documents": [anthropic.md](anthropic.md), [aws.md](aws.md), [black-forest-labs.md](black-forest-labs.md), [azure.md](azure.md), [google-cloud.md](google-cloud.md), [hetzner.md](hetzner.md), [linkup.md](linkup.md), [mailjet.md](mailjet.md), [mistral.md](mistral.md), [openai.md](openai.md), [scaleway.md](scaleway.md), [staan.md](staan.md), [verda.md](verda.md).

**What the statuses mean**

- **Public**: the official page loaded and was read.
- **Unverified**: an official page exists, but it could not be read automatically (it blocks bots, or loads only in a browser). Open it in a browser to confirm.
- **In DPA / In terms / In privacy policy**: there is no separate document; the content is part of the one named.
- **Partial**: published, but incomplete for our purpose (see Gaps and next steps).
- **Not public**: exists, but only at sign-up or on request.
- **None**: not found, or not documented.

## Gaps and next steps

Staan, Black Forest Labs and Linkup have the real gaps. The rest are pages to confirm in a browser, or documents that need a closer look.

| Provider | Gap | Next step |
|---|---|---|
| Staan | No public terms of service ("provided upon registration") | Get them at sign-up and file them with the note |
| Staan | No public DPA ("available upon request") | Request it; check it covers search query content and names the US fallback |
| Staan | Sub-processor list is a table in the privacy policy and leaves out the unnamed US fallback; no safeguard stated for it | Ask Staan to name the fallback and its safeguard, or to switch it off (EU-only routing) |
| Staan | No trust center, security page or certifications; no sub-processor change notices | Ask for a security overview and how changes are announced |
| Black Forest Labs | No public DPA ("available on request"); the self-serve terms make BFL a controller that trains on inputs and outputs | Get an enterprise agreement with DPA and zero retention, or at least send the "Training Opt Out" email |
| Black Forest Labs | Sub-processor list loads only in a browser; no change notices documented | Open the trust center in a browser; ask how changes are announced |
| Linkup | DPA text only visible when signing via DocuSign; terms (§6.5) allow training on prompts; queries routed to US/EU/Canada/APAC by default | Sign or request the DPA; get guaranteed EU processing (enterprise) and ZDR |
| Linkup | Two terms versions (linkup.so: August 2025; Notion: August 2026, not fully captured); no legal notice; ISO 27001 "in progress" | Get the August 2026 terms in full; confirm certification status |
| Scaleway | Sub-processor list, privacy policy, legal notice and contract pages returned 403; PDFs not re-checked | Open in a browser, or allow a plain `curl` check in Claude Code |
| OpenAI | All openai.com pages return 403 to automated requests | Open the sub-processor list, privacy policy and subscribe form in a browser |
| Anthropic, Mistral | Sub-processor lists and trust centers load only in a browser | Open in a browser and subscribe to change notices |
| Microsoft Azure | Two Service Trust Portal pages exist for the sub-processor list; the note now uses Microsoft's own short link (aka.ms/subprocessor) | Confirm in a browser which page is current |
| Hetzner | No SCCs; US/Singapore transfers rest on customer consent when picking the location. No change-notice subscription. | Use EU locations only; ask how sub-processor changes are announced |
| AWS | No imprint page; entity details only on the marketing-entities page. Bedrock keeps all Claude Fable 5 / 5.1 traffic for 30 days (abuse detection) | Confirm entity from the invoice; check Fable use and the Enterprise Frontier Safeguards program |
| Verda | No legal notice; the terms still name "DataCrunch Oy" (now Verda Cloud Oy); sub-processor list loads only in a browser | Use the current entity name; check FLUX inference (BFL, EU & US) if used |
| Mailjet, Microsoft Azure, Google Cloud | Legal notice is for a different group entity (Mailjet GmbH; Microsoft Deutschland GmbH) or a contracting-entity page | Confirm our contracting entity from the signed agreement |
